# Project Arrow

An open-source library of interactive economics diagrams — free, embeddable anywhere, scenario-driven, built around Canadian policy contexts.

**Live demo:** https://michaelfbarber.github.io/ProjectArrow

---

## What it is

Project Arrow is built on a single design principle: mathematical, graphical, and intuitive reasoning stay in sync. A student shifts a curve and simultaneously sees the graph update, the algebra re-solve step by step, and the equilibrium and welfare areas recalculate.

The math and the graph are the same thing said two different ways — and the tool shows that explicitly.

---

## Current features (v0.1)

- Drag supply or demand curves freely, or enter exact parameters
- Equilibrium computed analytically: Q* = (a−c)/(b+d), P* = a − b·Q*
- Step-by-step algebra panel updates in real time
- Toggle consumer surplus, producer surplus, deadweight loss, tax revenue
- Excise taxes, price floors, price ceilings with exact burden calculations
- Five Canadian policy scenarios: Strait of Hormuz, Vancouver rent ceiling, BC minimum wage, gasoline excise tax, carbon tax

Single HTML file. No framework, no build step, no platform dependency. Embed in Canvas via iFrame, drop on any website, open locally.
